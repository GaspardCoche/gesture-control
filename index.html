How to use with Claude Code

  1. Pinch on each element you want to fix → it lands in the Selection tray (left).
  2. Use ↑↓←→ arrow keys to zoom into parent / first child / siblings — like Selectorgadget.
  3. Type your overall intent in the textarea, or press V + dictate.
  4. Press K → a .md file downloads + your clipboard fills with the same content.
  5. In your terminal: claude < gesture-task-XXXXXXXX.md or paste the clipboard into a Claude Code session.
