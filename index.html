3 Modes, 5 Gestures

🔍

Inspect

Point to highlight DOM elements. Pinch to select and see computed styles, dimensions, tag info.

✏️

Draw

Pinch to draw freehand annotations directly on the page. Open hand to stop. Z to undo.

📏

Measure

Pinch twice to set two points — see the pixel distance between them instantly.
