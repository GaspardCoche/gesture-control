Welcome to Gesture Control

Hands-free DOM curation for Claude Code. Pick elements with gestures, dictate intent, and send a structured Markdown task in one move.

1. Paste a URL

Use the address bar above. The site loads in a sandboxed frame. If embedding is blocked, use the bookmarklet.

2. Pinch elements

Each pinch adds an element to your selection (numbered tray on the left).

3. Clap with both hands

Two-hand clap = send your task as Markdown. Or press K.

4. Open with Claude

claude < gesture-task.md in your terminal — done.
