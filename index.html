Features

O

Inspect Mode

Point at any DOM element to highlight it. Pinch to select and see computed styles, dimensions, and attributes.

/

Draw Mode

Freehand annotations directly on the page. Pinch to draw, open hand to release. Undo with Z.

*

Spotlight Mode

Focus attention on specific areas. Point to position, pinch to grab, spread to resize the spotlight.

>

Console Mode

Live console output overlay. Toggle debug borders and spacing visualization with gestures.

#

Measure Mode

Measure pixel distances between any two points on the page. Pinch to set measurement points.

+

Chrome Extension

Works on any website. Install the extension and use gestures on live production sites.
