How it works

1. Load a site — paste a URL or use the bookmarklet on the live site.
2. Pinch elements — each pinch adds an element to your selection (right panel, numbered).
3. Pick a template or write intent — Accessible / Modernize / Mobile / Cleanup, or your own description.
4. Ask Claude — streams the answer with diagnosis + CSS snippet + rationale.
5. Apply CSS (when same-origin) — Claude's CSS is applied directly to your selected elements with undo.
6. Export — .md file or clipboard for claude < gesture-task.md.
